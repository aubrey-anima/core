# 记忆漂移与人设偏移:2026 技术盘点与移植判断

> 2026-08-18 上网盘的。两个病是陪聊产品投诉量前二(记不住 / 人设漂),
> 也是 ANIMA「她的决定从世界里长出来」这条线的直接竞争力所在。
> 结论先行:**偷机制,不搬框架**;引擎的架构方向已被行业验证是对的,缺的是四个机制和一把尺子。

## 共同的病根

两个病是同一个病根的两张脸:**把状态存在模型的上下文里**。上下文一满,记忆靠挤、
人设靠开头那段提示词的注意力 —— 而注意力衰减是可测的(8 轮内显著漂移,开头 token
的注意力随窗口增长递减)。行业 2025–2026 收敛出的答案和 ANIMA 的地基是同一句话:
**状态住在模型外面,提示词每轮从权威状态现折出来**。引擎已经这么建了(stance /
关系 / 需求 / 量全在世界里),所以下面的判断都是「补机制」不是「换地基」。

## 记忆这一半

**基准**:LoCoMo、LongMemEval、BEAM(1M/10M token 档)。SOTA 是 Hindsight
(2025-12,LongMemEval-Medium 91.4% / LoCoMo 89.6%)。

**四波架构**(全部可考,许可都和 AGPL 兼容):

| 路线 | 代表 | 机制 | 开源 |
|---|---|---|---|
| 分层代理式 | Letta(原 MemGPT) | core/recall/archival 三层,agent 用工具自己决定读写 | Apache-2.0 |
| 事实抽取服务 | Mem0 | 对话里被动抽事实→存→下轮注入 | Apache-2.0 |
| **时间知识图谱** | Zep / Graphiti | 每条事实带 `valid_at`/`invalid_at`,答得出「那时她信什么」 | Apache-2.0 |
| 多图/笔记 | MAGMA、A-MEM(Zettelkasten 原子笔记互链)、Hindsight(facts/experiences/entity/**beliefs** 四网络) | 图为 2025–26 前沿 | 部分开源 |

**值得偷的四个机制**(ANIMA 的记忆 2.0 是 generative-agents 系:三因子 + 反思 +
遗忘曲线 —— 这条线 2023 年就有了,前沿在它之上加的是这四样):

1. **事实带时间有效期**(Graphiti):`valid_at`/`invalid_at`。ANIMA 的关系图 `edges`
   是闭集谓词 + 只增不减,一段友谊破裂靠反转时 drop —— 有效期是同一件事的更诚实写法,
   还顺便解「她曾经信过什么」。
2. **信念与事实分型**(Hindsight 的 beliefs 网络;另有 Typed Memory / provenance-role
   collapse 一文):「她经历的」「她听说的」「她以为的」是三种记忆。**这正是我们
   `event-ontology-gaps` 那条备忘里写的缺口**(被经历/被讲述/被期待)—— 外面的人
   也撞到了,而且给了名字和机制。八卦传播(gossip)落进记忆时今天就没分型。
3. **写入准入**(A-MAC):不是每句话都配成为记忆 —— 效用/置信/新颖/近因/类型五因子
   打分再收。ANIMA 的记忆触发器已有雏形,缺一道显式的准入闸。
4. **闲时固化**(sleep-time compute;TiMem;OpenClaw Auto-Dream 的「梦周期」):
   离线扫描-提炼-互链-修剪。**ANIMA 有天然的挂点:世界自己的夜晚** —— 反思已经在,
   把它挪到世界时钟的夜里跑,机制和叙事第一次是同一件事。

**移植判断:偷机制,不搬框架。** Graphiti 要 Neo4j/FalkorDB,Letta 要接管 agent
循环 —— 而 ANIMA 的纪律是记忆投影在进程里、世界住 Redis、派生数据不存两份。
搬框架 = 多一个后端 + 多一种不一致的坏法;四个机制全都能在现有 store 上实现。

## 人设这一半

**机理**(有代码可复现):

- 注意力衰减:persona 提示词坐在上下文开头,窗口越满它被读得越少;8 轮内可测出显著
  漂移(Measuring and Controlling Instruction (In)Stability,官方代码
  github.com/likenneth/persona_drift;提出 split-softmax,推理期干预,**要 logits
  访问,只对自托管开源模型可用**)。
- 吸引子态(2026):长对话收敛到稳定行为模式;定期重申指令只有温和改善,**按检测到的
  漂移动态调提示词效果更好**,重置有效但断连续性。
- PersonaDrift 基准:模拟 60 天使用,CUSUM 这类无监督统计就能测出渐进漂移。

**对策阶梯**(按 ANIMA 可用性排):

1. **人设注在尾部,不只在头部**。近因压过首因 —— 引擎握着 `prompt_blocks` 拼装权,
   这是零成本的一手。和 `prompt-position-is-weight`(提示词是权重)那条旧账是同一课。
2. **漂移要可测**:风格向量 + CUSUM,或自一致性探针。没有尺子的「我们人设稳」和
   没有测试的「代码没 bug」是同一句话。
3. **状态外置**(已是地基,见上)—— stance 惯性走提示词压力、关系走投影,漂移无处累积。
4. **角色特化模型**:CoSER-8B/70B(MIT,LLaMA-3.1 底,771 本书 17,966 个角色,
   given-circumstance acting 训练;InCharacter 75.8%、LifeChoice 93.5%,追平 GPT-4o)。
   LLM 客户端本来就是注入的 —— 自托管部署可以直接换。
5. **社区实践对照**(SillyTavern World Info / 向量记忆 / MemoryBooks):按相关性把世界
   设定动态注入 —— ANIMA 的本体 + 感知 + 预算就是这件事的结构化版,方向无需借。

**尺子选型**:CharacterEval(中文基准,77 个角色、4,564 例,评一致性/知识/吸引力
三面)—— 和「中文优先」纪律同向;PersonaGym 的五维度可参考。行业趋势文把 KPI 换成
「情绪改善率、记忆准确率、人格一致性」—— 后两个引擎测得出来。
